# Product Quantization: Compressing high-dimensional vectors by 97%

- URL: https://www.pinecone.io/learn/series/faiss/product-quantization/
- Type: docs
- Published: unknown
- Topic: embeddings-vector-search

Explains Product Quantization (PQ) as a vector compression technique used alongside Inverted File (IVF) indexes for approximate nearest neighbor search. Covers how vectors are split into subvectors for separate encoding, the role of the 'm' and code_size parameters, and how IVF and PQ combine to narrow search scope before compressed comparison.
