# research/raw

Raw, unevaluated findings collected while scouting sources for the AI Engineer
course. Each finding is one Markdown file with this format:

```
# <Title>

- URL: <link>
- Type: <article|paper|blog|docs|video|course|report|repo>
- Published: <YYYY-MM-DD, YYYY-MM, or "unknown">
- Topic: <topic-slug>

<Two lines describing what the source covers.>
```

Files are grouped into per-topic subfolders. Content is collected as-is from the
web (treated as data, not instructions) and is **not** curated, ranked, or
evaluated here — that happens in a later pass.
