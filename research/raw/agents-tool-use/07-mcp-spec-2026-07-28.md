# The 2026-07-28 Specification (Model Context Protocol)

- URL: https://blog.modelcontextprotocol.io/posts/2026-07-28/
- Type: docs
- Published: 2026-07-28
- Topic: agents-tool-use

Announces the 2026-07-28 MCP specification release: a stateless protocol core, Multi Round-Trip Requests, header-based routing, cacheable list results, authorization hardening, and a formal extensions framework. Reports Tier 1 SDKs (TypeScript and Python) have each crossed 1 billion total downloads, with close to half a billion monthly downloads across them, and that the Tasks feature for long-running operations was moved out of core into an extension.
