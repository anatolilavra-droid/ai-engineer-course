# The Evolution of Tool Use in LLM Agents: From Single-Tool Call to Multi-Tool Orchestration

- URL: https://arxiv.org/pdf/2603.22862
- Type: paper
- Published: 2026-03
- Topic: agents-tool-use

An arXiv survey tracing how LLM agent tool use has progressed from single-tool function calls to orchestrating multiple tools within a single agent turn or plan. Covers the technical evolution of tool-calling interfaces and orchestration strategies in LLM agents.
