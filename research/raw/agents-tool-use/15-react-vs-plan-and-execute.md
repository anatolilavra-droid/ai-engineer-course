# ReAct vs Plan-and-Execute: A Practical Comparison of LLM Agent Patterns

- URL: https://dev.to/jamesli/react-vs-plan-and-execute-a-practical-comparison-of-llm-agent-patterns-4gh9
- Type: article
- Published: unknown
- Topic: agents-tool-use

Explains the ReAct (Reason + Act) pattern where an LLM alternates between generating a thought, taking an action (tool call), and processing an observation in a loop until producing a final answer. Contrasts ReAct's step-by-step adaptivity and "short-term thinking" limitation on complex, interdependent tasks against the Plan-and-Execute pattern.
