# Securing AI agents: When AI tools move from reading to acting

- URL: https://www.microsoft.com/en-us/security/blog/2026/06/30/securing-ai-agents-ai-tools-move-from-reading-acting/
- Type: blog
- Published: 2026-06-30
- Topic: agents-tool-use

Microsoft Security Blog post on risks that emerge when AI agents move from passively reading data to actively taking actions via tools, including over-privileged agents, static/hardcoded credentials, limited visibility/logging, prompt injection exposure, and insecure tool or plugin integrations. Discusses identity and access control issues where a compromised agent with broad tool permissions can enable lateral movement across connected systems.
