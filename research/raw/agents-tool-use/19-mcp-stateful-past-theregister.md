# Model Context Protocol prepares to break with its stateful past

- URL: https://www.theregister.com/devops/2026/07/23/model-context-protocol-prepares-to-break-with-its-stateful-past/5276722
- Type: article
- Published: 2026-07-23
- Topic: agents-tool-use

News coverage of the upcoming MCP specification change that removes protocol-level session/state tracking, moving to a stateless protocol core where client identity, protocol version, and capabilities are carried in per-request metadata instead of a persistent session. Covers implications of this architectural shift for MCP client and server implementers.
