# Google's Agent2Agent Protocol Explained

- URL: https://galileo.ai/blog/google-agent2agent-a2a-protocol-guide
- Type: blog
- Published: 2026
- Topic: agents-tool-use

Describes Google's Agent2Agent (A2A) protocol, an open-source standard (introduced April 2025) that lets autonomous AI agents discover, authenticate, and interact with each other across implementations and hosting platforms. Notes A2A is built on Server-Sent Events, HTTP(S), JSON-RPC, and OAuth 2.0, and supports agent discovery, task delegation, message exchange, streaming updates, and artifact sharing; reports ADK now has native A2A support and the protocol has adoption from 150+ organizations by 2026.
