# LLM Function Calling 2026: Tool Use Across Providers

- URL: https://futureagi.com/blog/llm-function-calling-2025/
- Type: blog
- Published: 2026
- Topic: agents-tool-use

Explains function calling (tool use) as the contract between an LLM and an application: the model receives a prompt plus a tool catalog, decides whether to call a tool, and emits a structured call with typed arguments. Notes that standardized protocols such as Model Context Protocol (MCP) and Agent2Agent (A2A) have emerged to enrich the tool ecosystem around this core mechanism.
