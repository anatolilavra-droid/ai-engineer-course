# Online vs Offline AI Evals: When to Use Each - Inngest Blog

- URL: https://www.inngest.com/blog/online-vs-offline-ai-evals-when-to-use-each
- Type: blog
- Published: unknown
- Topic: evals

Explains the distinction between offline evals (run on curated datasets before deployment, providing repeatability and fast iteration) and online evals (scoring each production interaction as it happens using quality heuristics and safety checks rather than reference outputs).
Recommends running both approaches together: offline to catch regressions before release, online to measure real-world behavior that offline testing can only approximate.
