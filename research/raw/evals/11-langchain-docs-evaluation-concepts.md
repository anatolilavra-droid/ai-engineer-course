# Evaluation Concepts - Docs by LangChain (LangSmith)

- URL: https://docs.langchain.com/langsmith/evaluation-concepts
- Type: docs
- Published: unknown
- Topic: evals

LangChain/LangSmith documentation covering core evaluation concepts, including the distinction between offline evaluation (pre-deployment, curated datasets, reference outputs) and online evaluation (production monitoring on live traffic without reference outputs).
Describes offline evaluation as the standard mechanism for CI/CD checks before prompt, model, or retrieval changes reach users.
