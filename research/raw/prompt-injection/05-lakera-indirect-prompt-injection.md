# Indirect Prompt Injection: The Hidden Threat Breaking Modern AI Systems

- URL: https://www.lakera.ai/blog/indirect-prompt-injection
- Type: blog
- Published: unknown
- Topic: prompt-injection

Explains indirect prompt injection (IPI) as an attack that targets data an AI system ingests — webpages, PDFs, MCP metadata, RAG documents, emails, memory, and code — rather than the direct prompt. Describes how agentic capabilities (browsing, retrieving, writing, executing) increase the impact of hidden instructions embedded in ingested content.
