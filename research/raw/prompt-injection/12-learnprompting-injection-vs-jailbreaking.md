# Prompt Injection vs. Jailbreaking: What's the Difference?

- URL: https://learnprompting.org/blog/injection_jailbreaking
- Type: blog
- Published: unknown
- Topic: prompt-injection

Explains the distinction between prompt injection (overriding developer instructions via untrusted input) and jailbreaking (bypassing model safety training through persuasion or linguistic manipulation). Frames prompt injection as an architectural/application-layer issue and jailbreaking as a model safety-tuning issue.
