# Prompt Injection vs Jailbreaking: What's the Difference?

- URL: https://www.promptfoo.dev/blog/jailbreaking-vs-prompt-injection/
- Type: blog
- Published: unknown
- Topic: prompt-injection

Compares prompt injection and jailbreaking, noting that jailbreaks defeat model safety training (a vendor-side fix) while prompt injection places instructions into a trusted context so the application acts on them (an application-builder-side fix). Notes jailbreaks typically rely on linguistic persuasion rather than external data manipulation.
