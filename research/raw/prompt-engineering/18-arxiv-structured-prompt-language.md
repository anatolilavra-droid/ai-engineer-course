# Structured Prompt Language: Declarative Context Management for LLMs

- URL: https://arxiv.org/pdf/2602.21257
- Type: paper
- Published: 2026-02
- Topic: prompt-engineering

An arXiv paper proposing a declarative "structured prompt language" for managing LLM context and prompt composition, aiming to make prompt/context construction more systematic than ad hoc string templating. Relevant to prompt optimization and structured-output workflows as an alternative, code-like approach to composing prompts.
