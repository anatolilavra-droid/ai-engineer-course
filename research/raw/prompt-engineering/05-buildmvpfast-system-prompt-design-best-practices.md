Guide on system prompt design covering role definition, chain-of-thought reasoning, few-shot pattern teaching, constraints, context ordering, and structured output specification as core techniques. Discusses "output contracts" (format, length, tone, required sections) and production defenses against user attempts to override system instructions, such as explicitly stating that system instructions take precedence.
