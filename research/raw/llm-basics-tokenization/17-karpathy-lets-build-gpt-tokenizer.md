# Let's build the GPT Tokenizer (Andrej Karpathy)

- URL: https://x.com/karpathy/status/1759996549109776702
- Type: video
- Published: 2024-02
- Topic: llm-basics-tokenization

A roughly 2 hour 13 minute lecture by Andrej Karpathy that builds the GPT tokenizer from scratch, presenting tokenization as a separate stage of the LLM pipeline with its own training set and training algorithm (Byte Pair Encoding), implementing encode() and decode() functions. Accompanied by the minbpe GitHub repository containing minimal, clean BPE implementation code referenced throughout the video.
