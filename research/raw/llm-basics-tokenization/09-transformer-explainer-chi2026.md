# Transformer Explainer: Learning LLM Transformers with Interactive Visual Explanation and Experimentation

- URL: https://research.ibm.com/publications/transformer-explainer-learning-llm-transformers-with-interactive-visual-explanation-and-experimentation
- Type: paper
- Published: 2026
- Topic: llm-basics-tokenization

Describes an interactive visualization tool, presented at CHI 2026 (Barcelona, April 13-17), that runs a live GPT-2 instance in the browser so non-experts can learn transformer internals. The tool overviews the transformer's data flow with on-demand explanations that gradually reveal mathematical details and lets users experiment with custom input and hyperparameters, observing next-token predictions in real time.
