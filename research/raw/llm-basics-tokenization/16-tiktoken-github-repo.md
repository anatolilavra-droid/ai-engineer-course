# GitHub - openai/tiktoken: tiktoken is a fast BPE tokeniser for use with OpenAI's models

- URL: https://github.com/openai/tiktoken
- Type: repo
- Published: 2026-08
- Topic: llm-basics-tokenization

The official OpenAI repository for tiktoken, a fast Byte Pair Encoding tokenizer used with OpenAI's models, with its latest release dated August 17, 2026. Documents the encode/decode API, notes it is 3-6x faster than comparable open-source tokenizers, and covers encodings such as cl100k_base (GPT-3.5/GPT-4) and o200k_base (GPT-4o) along with use cases like token counting for cost and context-length estimation.
