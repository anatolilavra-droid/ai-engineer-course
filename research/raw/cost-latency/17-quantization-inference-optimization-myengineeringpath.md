# LLM Inference Optimization — Quantization, Distillation & Speed (2026)

- URL: https://myengineeringpath.dev/genai-engineer/inference-optimization/
- Type: article
- Published: 2026
- Topic: cost-latency

Explains quantization approaches reducing weight/activation precision from 16/32-bit to 8-bit, 4-bit, or 2-bit integers, reporting 8-bit quantization speeds up prefill by 20-30% and decode by 40-60%. States INT8 halves memory with under 1% quality loss, while INT4 cuts memory by 75%, letting a 70B model run on a single GPU.
