# Dynamic Model Routing and Cascading for Efficient LLM Inference: A Survey

- URL: https://arxiv.org/html/2603.04445v1
- Type: paper
- Published: 2026-03
- Topic: cost-latency

Survey paper distinguishing model routing (a single decision mapping a query to one model) from model cascading (sequential escalation to larger models when initial responses are insufficient). References RouteLLM (2025) and UniRoute (Jitkrittum et al., 2026), the latter addressing routing to previously unseen models at test time via feature-vector representations.
