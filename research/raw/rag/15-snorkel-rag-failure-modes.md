# RAG failure modes: common pitfalls and solutions

- URL: https://snorkel.ai/blog/retrieval-augmented-generation-rag-failure-modes-and-how-to-fix-them/
- Type: blog
- Published: unknown
- Topic: rag

Enumerates common RAG failure modes including poor document chunking, dense retrieval mismatch (retrieved chunks appear similar in embedding space but are not truly relevant), and embedding drift as the underlying embedding model or indexed corpus changes over time. Frames retrieval failure as the most prevalent cause of RAG system quality degradation.
