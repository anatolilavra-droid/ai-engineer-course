# What is Agentic RAG? Everything You Need to Know in 2026

- URL: https://www.lyzr.ai/blog/agentic-rag/
- Type: blog
- Published: 2026
- Topic: rag

Defines Agentic RAG as an approach that wraps a retrieval-augmented generation pipeline inside an LLM agent that decides when to retrieve, what to retrieve, and whether the generated answer is sufficient. Contrasts this decision-driven loop with the fixed single-pass retrieval sequence used in traditional RAG.
