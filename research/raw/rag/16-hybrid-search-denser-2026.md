# Hybrid Search for RAG: Combining BM25 and Dense Vector Search (2026 Guide)

- URL: https://denser.ai/blog/hybrid-search-for-rag/
- Type: blog
- Published: 2026
- Topic: rag

Describes hybrid search architecture combining sparse keyword retrieval (BM25) with dense vector search, fused via Reciprocal Rank Fusion (RRF). Reports benchmark figures on the WANDS e-commerce dataset where a tuned hybrid setup reaches 0.7497 NDCG versus 0.6983 for BM25 alone and 0.6953 for pure vector search.
