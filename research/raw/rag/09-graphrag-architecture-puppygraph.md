# GraphRAG Architecture: Components, Workflow & Implementation Guide

- URL: https://www.puppygraph.com/blog/graphrag-architecture
- Type: blog
- Published: unknown
- Topic: rag

Breaks down GraphRAG into three phases: construction (building a knowledge graph from text by identifying entities and links), search (scanning the graph for relevant nodes, edges, or clusters given a user query), and synthesis (an LLM combining retrieved graph information with the query to produce a response). Positions GraphRAG as addressing multi-hop reasoning cases where flat vector retrieval lacks relational context.
